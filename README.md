**Platform and DevOps engineer.** I build Kubernetes and Terraform delivery systems — and the
tooling that verifies them before they ship. Now moving into **MLOps and AgentOps**: bringing the
same delivery, guardrails and observability to ML pipelines and AI agents.

Five years running production infrastructure on AWS: EKS and kubeadm clusters, Terragrunt-managed
environments, Argo CD delivery, and the observability and security work that keeps them honest.
Based in Ahmedabad, India.

### What I work on

- **Platform and infrastructure as code** — multi-environment AWS infrastructure with Terraform
  and Terragrunt: reusable modules, per-environment and per-service isolation, S3 remote state,
  and plan-gated, peer-reviewed delivery. Managed EKS in production; kubeadm where the economics
  favour it.
- **Delivery** — GitOps with Argo CD under an app-of-apps model, managing platform charts
  alongside service charts. GitHub Actions pipelines with real gates — lint, test, security scan,
  containerise, promote — behind branch-protection rulesets and enforced Conventional Commits.
- **AI-assisted verification** — MCP servers and Claude Code skills that check Terraform and Helm
  changes before a human reviews them, behind enforced guardrails: migration safety-gating,
  human-in-the-loop review, and an audit trail for every agent action. Including a
  gateway-mediated observability layer that gives agents governed, least-privilege access to
  telemetry.

### Currently

Building out the AI-assisted infrastructure work — governed agent access to telemetry, and
verification skills that catch unsafe Terraform and Helm changes before review.
